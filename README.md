# TCP Chat Server — сервер чату через TCP

**Орієнтир:** 3 тижні (тижні 8–10)

## Мета
Освоїти асинхронну мережеву взаємодію, протокол повідомлень і керування багатьма клієнтами.

## Функціональні вимоги
- Сервер і простий консольний клієнт; унікальні псевдоніми, список учасників, загальні та приватні повідомлення.
- Кадрування: 4-байтовий розмір у мережевому порядку байтів + UTF-8 payload. Максимум — 64 КіБ.
- Обробка часткового читання, кількох повідомлень в одному читанні, раптового відключення клієнта.
- Обмежена черга вихідних повідомлень; повільного клієнта відключати за політикою. Коректне завершення сервера.

## Технології
Boost.Asio або standalone Asio, TCP sockets, `async_read`/`async_write`; strand для послідовного доступу до сесії, якщо `io_context` обслуговують кілька потоків.

## План
1. Формат кадру й типи команд. Тести кодування, декодування, обмеження довжини.
2. accept і сесія одного клієнта з гарантованим часом життя під час асинхронних операцій.
3. Реєстрація псевдоніма, розсилка, приватні повідомлення; захищений реєстр сесій.
4. Окрема черга запису: без накладання `async_write` на одному socket.
5. Клієнт та інтеграційні тести: фрагментація, відключення, повільний читач.

## Критерій готовності
- [ ] ≥ 50 локальних клієнтів обмінюються повідомленнями без пошкодження кадрів
- [ ] Завеликий кадр відхиляється до виділення великого буфера
- [ ] Черги мають межі

## Розширення
Кімнати, TLS, автентифікація.
